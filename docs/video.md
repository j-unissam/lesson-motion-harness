# video.md — 교실 TV 수업 영상 화면 규칙

**누가 · 어디서 보나:** 교실 앞 TV로 반 전체가 함께 본다. 맨 뒷자리 학생도 읽을 수 있어야 한다.
**선생님이 정한 것 (2026-11-14):** 배경 = **밝은 종이** · 글자 = **여백을 둔다** · 마지막 정리 화면 = **개념 흐름 + 질문 한 줄**. (세 가지 모두 기본값 그대로 고름)

> 색 · 글꼴 · 크기 값은 `docs/design.md`, 움직임 · 시간은 `docs/motion.md` 에만 있다. 이 문서는 그 값을 **교실 TV에서 어떻게 지키는지**만 정한다. 여기서 새 값을 만들지 않는다.
> 없는 값이 필요하면 지어내지 말고 "새 후보"로 묻는다.

## 1. 글자 최소 크기

| 무엇 | 최소 | 근거 |
|---|---|---|
| 읽는 글자 (본문 · 부제 · 설명) | **44px** (`text-body`) | design.md 2장 · 양식 `templates/look/design.md` "44px 이상" |
| 라벨 · 쪽수 · 출처 | **32px** (`text-label`) — 이보다 작은 읽는 글자는 없다 | design.md 2장 |
| 손글씨 이름표 | **56px** (`text-hand`) — 손글씨 글꼴이 작게 나와서 고딕 36px 와 글자 높이가 같도록 키운 값. 56px 아래로 내리지 않는다 | design.md 2장 (ref8 1주차 제작 노트: 손글씨는 글자 높이 30px 이상) |
| 장면 제목 | 72px (`text-title`) | design.md 2장 |

- 기준은 1920×1080 영상 px. 화면을 줄여 미리 볼 때도 이 값으로 판단한다.
- 예외: 바탕 질감(종이 결 · 나뭇결)과 모눈 줄은 글자가 아니므로 해당 없음. **그림 속 글자(숫자 · 낱말)는 글자다** — 32px 이상.
- 카메라가 시작 때 × 0.918 크기에서 다가오므로(motion.md 5장 push-in × 1.090), **첫 장면 글자는 처음 약 6초 동안(ref8 1.0 → 6.25) 최대 8% 작게 보인다.** 첫 장면 위쪽 작은 글줄도 32px 아래로 두지 않는다.

## 2. 배경

**밝은 종이로 한다** (선생님 고름).

- 바탕은 언제나 `desk-paper-ground` 부품 하나: 나무 책상(`color-desk`) 위 밝은 모눈종이(`color-bg` `#f4ece0`). 장면마다 바꾸지 않는다.
- 어두운 화면은 **영상 맨 처음 0.5s 와 맨 끝 0.75s 뿐**이다 (motion.md `dur-fade-in` · `dur-fade-out`). 장면 사이에 검은 화면 · 흰 화면을 넣지 않는다 — 장면 사이는 지우개로 지운 빈 종이(0.13s)다.
- 글자와 배경 대비 (design.md 1장): `ink` 10.7:1 · `ink-soft` 4.65:1 · `accent` 3.0:1. 교실 TV는 밝기 · 대비가 낮게 보일 때가 많으므로 **읽는 글은 `ink` 를 먼저** 쓰고, `ink-soft` 는 부제 · 라벨 · 출처에만, `accent` 는 굵은 32px 이상(번호 · 용어 이름 · 말풍선 · 설명 화살표 위 말)에만 쓴다.
- 노랑 · 주황 알약 위 흰 글자는 대비가 3:1 미만이다 (design.md 1장). 교실 TV로 시험해 흐리게 보이면 알약 글자만 `ink` 로 바꾸는 것을 새 후보로 묻는다.
- 화면 전체를 덮는 사진은 쓰지 않는다. 사진은 `data-card` 의 그림 칸 안에만 (design.md 6장).

## 3. 글자

**여백을 둔다** (선생님 고름). 한 화면에 글이 적고, 종이 안쪽 여백이 넓다.

| 규칙 | 값 | 근거 |
|---|---|---|
| 한 화면의 글 덩어리 | 제목 1 + 부제 1 + 아래 강조 문장 1. **정의 장면은 부제 자리에 정의(`definition-note`: 용어 + 문장 세 줄까지)** 가 들어간다. 그 밖의 글은 그림 이름표 · 판정 말 · 출처뿐 | ref8 0:20 · 1:39 장면 구성 (design.md 4장 구도) |
| 제목 길이 | 16자 안쪽, 한 줄 | `title-highlight` 부품 주석 |
| 부제 길이 | 30자 안쪽, 한 줄 | 같음 |
| 강조 문장 길이 | 32자 안쪽, 한 줄 | 같음 |
| 정의 문장 | 한 줄 26자 안쪽 · 세 줄까지 | `definition-note` 부품 주석 |
| 이름표 · 판정 말 | 이름표 10자 안쪽 · 판정 2~6자 | `data-card` · `verdict-bubble` 부품 주석 |
| 강조 표시 | 강조 문장 **띠 한 군데** + 정의 문장 **밑줄 한 군데**까지 | design.md 1장 (ref8 1:39) |
| 글꼴 | 제목 · 본문 · 라벨 = Pretendard / 손글씨 = 그림 옆 이름표에만 | design.md 2장 |
| 글자가 나타나는 법 | 연필로 써진다 (`write-speed` 650px/s). 예외 넷: 알약 이름표 · 도장 · 개념 흐름 동그라미 안 낱말과 아래 설명 · 카운트다운 숫자 | motion.md 2장 "써지지 않는 글자" |

- 글이 길어 위 길이를 넘으면 **글자를 줄이지 말고** 장면을 둘로 나눈다.
- 쓰는 시간은 줄 길이로 정해진다 (motion.md 1-2). 한 장면에 그릴 것이 많아 20초를 넘으면 (ref8 장면 길이 13~20s, motion.md 4장) 장면을 나눈다.

## 5. 표기 — 교과서 표기 그대로

- **내용은 `docs/textbook/` 의 md에서만**, 쪽수와 함께 가져온다 (README "지킬 것").
- 교과서 문장을 옮기는 자리(정의 · 강조 문장 · 질문 · 자료 이름)는 **글자 · 띄어쓰기 · 문장부호를 교과서 그대로** 쓴다. 맞춤법이 이상해 보여도 고치지 않는다.
  - 예: "키 35(cm), 몸무게 10(kg)" (교과서 100쪽) → `35cm` · `35 cm` 로 바꾸지 않는다.
  - 예: "표현·처리·저장" (교과서 98쪽) 의 가운뎃점 `·` 을 쉼표로 바꾸지 않는다.
  - 예: 따옴표는 교과서처럼 ‘ ’ · “ ” (곧은 따옴표 `'` `"` 로 바꾸지 않는다).
- 용어는 교과서 낱말 그대로: "아날로그 데이터" · "디지털 데이터" · "인공지능" · "레이블링" 등. 영어 약자(AI)는 교과서에 있을 때만.
- 단원 · 과목 이름은 교과서 표기 그대로: 과목 · 단원 라벨은 `실과 · 6. 데이터와 인공지능` 처럼 교과서 대단원 이름을 쓴다.
- **출처:** 교과서 문장 · 그림을 쓴 화면에는 출처 자리에 `교과서 ○쪽` 을 적는다 (`data-card` · `definition-note` 의 출처 자리, 또는 장면 하나에 한 번 `title-highlight` 의 `#th-source`). 사진은 `src/assets/photos/SOURCES.md` 에 출처를 적는다.
- 제목 · 부제는 교과서 소제목을 그대로 쓰는 것이 기본이다. 줄여 쓸 때는 장면표에 원래 소제목과 쪽수를 같이 적고 선생님께 확인한다.
- 교과서 그림 · 사진을 그대로 넣지 않는다. 그림은 직접 그린다 (design.md 6장).

## 6. 부품

`src/parts/` 의 부품만 쓴다. 장면은 부품을 조합해서 만든다.

| 부품 | 한 화면에 | 쓰는 때 |
|---|---|---|
| `desk-paper-ground` (바탕) | 늘 1 | 모든 장면의 맨 아래 |
| `subject-label` (과목 · 단원) | 늘 1 | 모든 장면. 지워지지 않고 번호만 바뀜 |
| `number-construct` (연도 · 시대) | 0 ~ 1 | 영상 첫 장면(단원 번호 · 제목)에만. 다른 부품과 같이 쓰지 않음 |
| `title-highlight` (제목 + 강조 문장) | 1 | 첫 장면을 뺀 모든 장면 |
| `data-card` (자료 + 이름) | 0 ~ 6 | 가운데 칸. 테두리 카드는 4장까지 한 줄, 그림 + 알약은 3칸 × 2줄까지 (4장 "가운데 칸 배치") |
| `definition-note` (정의 · 사료 · 정리) | 0 ~ 1 | 용어 정의 장면. 이때 가운데 칸에 카드를 같이 두지 않는다 |
| `verdict-bubble` (판정 · 강조) | 말풍선 0 ~ 1 · 도장 0 ~ 4 | 말풍선: 그림 · 그래프 옆 짧은 판정 (ref8 0:33). 도장: 퀴즈 답, 카드 아래에 하나씩 (ref8 1:21 ~ 1:24) |
| `concept-flow` (개념 흐름) | 0 ~ 1 | 마지막 정리 화면에만. `title-highlight` 와 같이 쓰고, 가운데 칸에 다른 부품을 두지 않는다 |

- 형광펜: `title-highlight` 의 띠 한 군데 + `definition-note` 의 밑줄 한 군데까지 (design.md 1장).
- 부품마다 바꾸는 부분 · 건드리지 않는 것 · 따로 움직이는 조각은 각 부품 html 맨 위 주석에 있다. 움직이는 순서와 시간은 motion.md 3장.
- 부품을 고치거나 새로 만들면 `src/parts/_check/` 에 견본을 다시 찍는다.
