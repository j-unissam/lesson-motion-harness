## 나중에 쓸 것 (움직임 단계)
- 움직임(`docs/motion.md`)은 **ref8 영상**으로 잰다. 장면 시각: 0:00 작도선 → 0:04 제목 화면 → 0:08 01 생활 속 데이터 → 0:24 02 데이터와 정보 → 0:36 03 아날로그 · 디지털 → 0:56 04 바꾸면? → 1:12 퀴즈 → 1:28 05 인공지능이란? → 1:44 06 활용하는 데이터 → 2:00 07 정리 (4초 간격 장면 모음으로 본 대략값).
- ref3~5 (vimeo) 는 이미지만 있다. 그 영상의 움직임까지 재려면 주소가 필요하다.
- ref8 장면 사이에는 빈 종이 화면이 끼어 있다 (지우개로 지우고 다음 장면을 그리는 흐름).
- 슬라이드 캡처(ref1 · ref2 · ref6 · ref7)에서 보이는 움직임 흔적: 연필이 선을 긋는 중(ref6), 형광펜 문장이 왼쪽부터 써지는 중(ref2 "새로…"), 말풍선이 오른쪽에서 밀려 들어오는 중(ref1).
